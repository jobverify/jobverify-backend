# WizKlub native vacancy repair

The original adapter returned `[]` without checking any source and treated an unrelated process `--dry-run` argument as permission to execute persistence code. The repaired adapter performs bounded streamed native requests, supports injected transport through both factory and run options, preserves exact caller abort reasons, and reports typed `WIZKLUB_COVERAGE_GAP` failures on transport, deadline, body, identity or markup drift. Imports have no persistence side effect.

Root-owned isolated Chrome captures on 2026-10-23 establish these facts:

- `https://www.wizklub.com/` returned HTTP 403. The dev home and About Us pages returned HTTP 200. Home Organization schema names Wizklub, links the current Wizklub Futurz LinkedIn identity in `sameAs`, and exposes `support@infinitylearn.com`. A schema social association is not an official recruiting handoff; `firstParty` stays false.
- Old native employer WizKlub Learning Pvt Ltd (`74233894`) and current Wizklub Futurz (`53495338`) reciprocate wizklub.com. Exact checked employer filters for India and Worldwide each expose no-match states. These observations do not establish company emptiness.
- The similarly named `/company/infinity-learn` is Canadian IT training, organization `24988334`, and reciprocates infinitylearn.co. Its captures are retained as rejected discovery evidence. The adapter never consumes that employer.
- Correct parent `/company/infinity-learn-by-sri-chaitanya`, organization `78106236`, describes Sri Chaitanya and has a native IN organization address. That address is identity evidence only; each vacancy must independently name its job country.
- Correct parent India and Worldwide listings expose twenty cards. Three reviewed role details explicitly identify WizKlub. Coding and Robotics Trainer (`4480357313`) names `Ambur, Tamil Nadu, India`, retains earliest observed listing date `2026-10-16`, and exposes enabled same-role Apply/sign-in. Area Sales Manager (`4478763469`) names `Tamil Nadu, India`, retains `2026-10-13`, and has the same active application evidence. Area Manager (`4477806380`) is explicitly no longer accepting applications and is excluded.

Two native India jobs are recovered in local `jobs.json`. Generic parent vacancies are never attributed to WizKlub. Only three reviewed branded details are requested; other parent cards remain unvisited by this adapter. Primary details expose relative publication text only. Recommended-job absolute dates belong to other roles and are ignored. Fetch time never becomes a publication date; first-ever publication and expiry remain unknown. Newly introduced primary `<time>` elements, JobPosting structured data, country/date/expiry microdata or changed identities fail review instead of silently retaining old assumptions. India/Worldwide date conflicts retain the earliest absolute observed date. Cities and organization addresses never supply vacancy countries.

Whole-company and India totals remain null. Inventory is `discovery-only`, listing and source scope are incomplete, and lifecycle cleanup is disabled. Missing descriptions remain null with partial detail health and remain publishable when brand attribution, explicit job country, publication and active application evidence still pass. No other eligibility gate was relaxed. Actual recovered jobs and a missing-description variant both produce two eligible jobs under `analyzePublishableJobs` as of 2026-10-23.

Captures are gzip-compressed. `fixtures/capture-manifest.json` records compressed-file, uncompressed-file and response-body SHA-256 hashes, exact URLs, status, final URLs and capture times. Separate DOM observations do not imply HTTP facts. The candidate metadata uses repository-relative artifact paths. These offline replays establish parser behavior against actual receipts; they do not guarantee future network availability or complete hiring coverage.

Verification: `node --test scraper/wizklub/script.test.js` passes 19 tests. Original transport regression run failed all eight tests with missing expected rejections. Native extraction initially returned no jobs before the parent listing repair; a regression asserted the two exact dated native jobs and failed. A separate new primary-time-without-datetime test also failed before its guard was fixed. Tests cover receipt replay, factory forwarding, eligibility with missing JD, date preservation, country ambiguity, closed/disabled applications, identity/scope/JobPosting/microdata/time drift, recommendation-date isolation, hash integrity, aggregate fetch/body deadlines, stream limits, unread-body cancellation, exact abort reasons and import side effects.
