Software Developer

LocationCoimbatore, India
Job TypeFull-Time

Location: Coimbatore
Openings: 2
Experience: 0–1 Year / Freshers
Type: Full-Time

Job Description

We are looking for enthusiastic and technically curious Software Developer Freshers to join our R&D Engineering Team. The ideal candidate should have a good understanding of programming fundamentals and basic exposure to frontend development, backend development, databases, Artificial Intelligence, Machine Learning, Generative AI, RAG, and Agentic AI concepts. This role is intended for candidates who may not have extensive industry experience but demonstrate strong technical fundamentals, logical thinking, problem-solving ability, curiosity, and willingness to experiment with emerging technologies.

Preferred Skills and Qualifications

  • Basic to good understanding of Python programming, including variables, data types, control flow, functions, object-oriented programming, exception handling, and common data structures.

  • Basic understanding of JavaScript, jQuery, and React, with awareness of how frontend applications communicate with backend services.

  • Basic understanding of REST APIs, backend fundamentals, and JSON/CSV/XML data formats.

  • Basic understanding of MySQL, including tables, relationships, primary/foreign keys, CRUD operations, joins, and basic query concepts.

  • Basic understanding of MongoDB, including collections, documents, CRUD operations, and the difference between SQL and NoSQL databases.

  • Basic conceptual understanding of Artificial Intelligence and Machine Learning, including supervised and unsupervised learning, classification, regression, model training, and evaluation.

  • Basic understanding of Generative AI and Large Language Models (LLMs), including how LLM-based applications are used in software solutions.

  • Basic understanding of software testing, debugging, logging, and identifying/fixing common programming errors.

  • Basic familiarity with Linux/command-line environments, package management, environment variables, and running applications/services.

  • Basic understanding of Retrieval-Augmented Generation (RAG), including document ingestion, chunking, embeddings, retrieval, context augmentation, and response generation.

  • Basic awareness of vector databases and similarity search; exposure to FAISS, ChromaDB, Pinecone, Weaviate, Milvus, or similar technologies is an advantage.

  • Basic conceptual understanding of Agentic AI, including AI agents, tool calling, function calling, planning, workflows, and multi-step task execution.

  • Exposure to AI-assisted development tools such as Claude Code, ChatGPT/Codex, GitHub Copilot, Cursor, or similar tools is preferred.

  • Academic projects, internships, personal projects, GitHub repositories, or proof-of-concepts involving software development or AI technologies are an advantage.

  • Ability to independently research documentation, technical articles, GitHub repositories, and other reliable resources to understand and solve technical problems.

  • Strong logical thinking, curiosity, and learning agility — able to explain technical concepts clearly, adapt quickly to unfamiliar technologies, and build or walk through small projects or proof-of-concepts confidently.

Responsibilities

  • Participate in R&D activities involving software development and emerging technologies.

  • Develop small prototypes and proof-of-concepts based on technical or business requirements.

  • Write and test Python-based applications and utilities.

  • Work with MySQL and MongoDB for basic data storage and retrieval requirements.

  • Develop or support simple frontend components using JavaScript, jQuery, and React.

  • Understand and integrate REST APIs and backend services.

  • Explore AI/ML, LLM, RAG, Vector Database, and Agentic AI technologies.

  • Experiment with AI-assisted development tools and emerging AI technologies.

  • Research technical problems and evaluate possible approaches and solutions.

  • Perform basic debugging, testing, and troubleshooting.

  • Document technical findings, experiments, and proof-of-concept results.

  • Collaborate with senior developers and R&D team members.

  • Continuously improve technical knowledge through self-learning and experimentation.
