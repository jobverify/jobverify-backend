# Noto fallback fonts

These unmodified fonts are distributed under the SIL Open Font License 1.1.
Each font's original license is included alongside it.

Source revision: `google/fonts@8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`.
Exact download URLs and SHA-256 hashes are recorded in `manifest.json`.

- [Noto Sans Symbols 2](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notosanssymbols2), version 2.008, is stored as `NotoSansSymbols2-Regular.ttf`. License: `LICENSE-notosanssymbols2.txt`.
- [Noto Emoji](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/notoemoji), version 3.002, is stored as `NotoEmoji.ttf` (upstream filename `NotoEmoji[wght].ttf`). License: `LICENSE-notoemoji.txt`.

Noto Emoji uses monochrome TrueType outlines so the native PDF renderer can
embed selectable contact symbols without relying on host fonts or color emoji
support. These fonts supplement DejaVu only where it lacks a source glyph.
